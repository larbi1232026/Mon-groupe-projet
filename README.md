# Installation et Déploiement

## Objectif
Permettre de compiler et lancer facilement le projet Parabox-like.

## Prérequis
- Java 17 (ou version compatible)
- Git

## Installation

### 1. Cloner le projet
git clone https://github.com/larbi1232026/Mon-groupe-projet

### 2. Aller dans le dossier
cd Mon-groupe-projet

### 3. Compiler
javac src/*.java

### 4. Lancer le jeu
java Main

## Remarques
- Le projet doit fonctionner sous Linux
- Aucun outil externe n’est nécessaire
