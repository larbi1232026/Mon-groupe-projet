# Branche Édition de plateau

## Objectif
Cette branche contient l'éditeur de niveaux du projet Parabox-like.

## Responsabilités
- créer un nouveau plateau
- modifier un plateau existant
- choisir un outil d'édition
- placer les éléments du niveau
- préparer l'intégration avec la persistance

## Éléments à éditer
- case vide
- mur
- joueur
- boîte
- cible
- boîte-monde

## Fichiers principaux
- LevelEditorFrame.java
- LevelEditorPanel.java
- EditorTool.java

## Dépendances
Cette branche dépend surtout :
- du modèle
- de l'interface graphique
- de la persistance pour la sauvegarde
