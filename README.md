# Branche Interface Graphique

## Objectif
Développer l'affichage graphique du jeu Parabox-like.

## Responsabilités
- afficher le plateau
- afficher le joueur, les murs, les boîtes et les cibles
- gérer les déplacements avec le clavier
- mettre à jour l'affichage après chaque mouvement
- créer une interface simple et lisible

## Fichiers principaux
- GameFrame.java
- GamePanel.java
- StartMenuFrame.java

## Fonctionnalités
- déplacement avec les flèches
- affichage du plateau
- interaction avec le modèle
