# Coordination du projet Sokoban Récursif

## Organisation de l'équipe

Nous sommes un groupe de 8 personnes.  
Le projet a été divisé en plusieurs tâches pour faciliter le travail en parallèle.

### Répartition des tâches

- Modèle (logique du jeu) → gestion des mondes, déplacements, règles
- Interface graphique → affichage avec Swing (GamePanel, GameFrame)
- Plateau → gestion des niveaux et des cases
- Solveur automatique → algorithme BFS récursif
- Interaction clavier → gestion des touches (déplacement, entrée/sortie)
- Tests → vérification du bon fonctionnement
- Installation → configuration et exécution du projet
- Coordination → organisation du projet et gestion GitHub

---

## Utilisation de GitHub

Chaque membre a travaillé sur une branche spécifique :

- `feature/modele`
- `feature/interface`
- `feature/plateau`
- `feature/solveur`
- `feature/installation`
- `feature/coordination`

Les branches ont ensuite été fusionnées dans la branche principale (`main`).

---

## Méthode de travail

- Travail en parallèle sur différentes branches
- Communication via WhatsApp
- Partage du lien GitHub avec toute l’équipe
- Tests réguliers après chaque ajout

---

## Difficultés rencontrées

- Gestion des mondes récursifs
- Synchronisation entre les différentes parties du code
- Gestion des entrées clavier
- Implémentation du solveur automatique

---

## Solutions apportées

- Division claire des tâches
- Utilisation de GitHub pour éviter les conflits
- Tests fréquents
- Correction progressive des bugs

---

## Conclusion

Le travail en groupe nous a permis de :
- développer un projet complet
- améliorer notre organisation
- apprendre à utiliser GitHub efficacement
