# Branche Modèle

## Objectif
Cette branche contient toute la logique du jeu Parabox-like.

Le modèle représente les données du jeu et gère les règles de déplacement.

## Responsabilités
- représenter le plateau (monde)
- représenter le joueur
- représenter les boîtes (simples et récursives)
- gérer les déplacements
- vérifier les mouvements autorisés
- gérer les entrées et sorties des boîtes
- vérifier si le niveau est terminé

## Fichiers principaux
- GameModel.java
- GameState.java
- World.java
- Position.java
- Direction.java
- CellType.java
- AbstractBox.java
- TargetBox.java
- WorldBox.java
